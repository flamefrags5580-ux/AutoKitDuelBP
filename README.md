# AutoKitDuelBP
Minecraft Bedrock addon with auto kit, clan, duel, admin controls, and arena reset.

This starter project includes a basic Bedrock behavior pack structure and command functions for core gameplay features.

## Features
- Auto kit assignment
- Clan creation and tracking
- Duel request flow
- Admin mode toggle
- Arena reset and cleanup

## Project structure
- `behavior_packs/AutoKitDuelBP/` – gameplay logic and commands
- `resource_packs/AutoKitDuelRP/` – optional resource pack metadata

## Basic usage
Run these in-game with the command console or function commands:
- `/function setup`
- `/function kit_warrior`
- `/function clan_create`
- `/function duel_request`
- `/function admin_mode`
- `/function arena_reset`

## Notes
This is a lightweight starting point meant to be expanded with custom menus, entity-based gameplay, or a more advanced duel system.
